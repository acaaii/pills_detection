Goal02 / 09

우리는 무엇을 목표로 할까

실제 서비스라면 추론 속도, 일반화 성능, 특정 알약에 대한 성능 중 무엇이 중요할까?
우리 팀은 정보가 제공된 알약들에 대한 “보장된 성능”과 “빠른 속도”를 목표로 설정했다.

Hypothesis03 / 09

실전을 가정한 첫 번째 시도

문제 인식

test set을 열어보기 전, 실제로 서비스를 서빙한다면 일반인이 무작위 배경에서 찍은 비정제 이미지를 분류해야 할 것이라 예상했다.

채택한 해결책

CycleGAN, Diffusion Model을 활용해 알약의 형태는 유지한 채 배경만 다양하게 증강하는 방법을 채택했다.

Memo 배경 증강 = 일반화 성능 향상 전략
Pivot04 / 09

가설이 무너진 결정적 순간

1

배경 증강 데이터를 train에 합쳐 학습 → val 점수가 오히려 크게 하락

2

원인을 파악하고자 test set을 오픈 (주어진 과제를 정확히 이해하기 위함)

3

test set이 train set과 배경·알약 구조 면에서 이미 매우 유사하다는 것을 확인

Insight → 배경 증강은 우리에게 주어진 실제 과제와 맞지 않다고 판단, 방향을 전환한다.
Pivot Point 가설 → 검증 → 방향 전환
Data Prep05 / 09

데이터를 다시 쌓다

1

AI Hub 데이터 확보

경구약제 데이터 약 5,800장을 추가로 확보해 데이터 양을 늘림

2

유사 이미지 제외

유사도 체크로 test set과 겹치는 이미지 제외 (금지된 TL-2 조합 외에도 유사 이미지 존재)

3

직접 검수

bbox 오류 및 미검출 이미지를 육안으로 검수해 약 350여 장 제거

Point 많을수록 좋다, 단 정확해야 한다
Synthetic Data06 / 09

진짜 같은 가짜 데이터 만들기

test와 train 이미지가 유사하다는 인사이트를 역이용해, 유사한 배경의 합성 데이터를 직접 제작했다.

01

누끼 따기

SAM으로 train 내 모든 알약 분리

02

배경 합성

포토샵으로 유사 배경 제작, 3~4개씩 배치

03

조명 입히기

배경색 추출 후 스크린 기법으로 조명 반영

04

명암·그림자

알약 내부 명도 차 계산, 그림자 생성

05

무작위 회전

알약을 랜덤 회전시켜 다양성 확보
